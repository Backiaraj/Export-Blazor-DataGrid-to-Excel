# Blazor DataGrid — Excel Export Examples

A comprehensive Blazor application demonstrating Excel export functionality using the [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid) component with multiple customization scenarios.

## Overview

This repository showcases how to integrate Excel export capabilities into a Blazor application using the Blazor DataGrid component. The sample includes practical examples for common export scenarios and demonstrates how to customize the exported Excel files with formatting, styling, and dynamic content.

## Features

- **Basic Excel Export** - Export grid data to Excel with a single click from the toolbar
- **Custom File Naming** - Set custom names for exported Excel files dynamically
- **Headers & Footers** - Add custom headers and footers to exported documents
- **Row & Column Styling** - Apply custom styling, colors, and formatting to rows and columns
- **Cell Customization** - Format individual cells conditionally based on data values
- **Header Cell Styling** - Customize header cell appearance with colors and formatting
- **Group Caption Customization** - Style grouped data and group caption rows
- **Aggregate Customization** - Format and customize aggregate rows in exports
- **Data Source Customization** - Export filtered or processed data with custom logic
- **Interactive Examples** - Explore 11 different export scenarios with live working examples

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/Export-Blazor-DataGrid-to-Excel.git
cd Export-Blazor-DataGrid-to-Excel
cd Grid_Excel_Export
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
